# Experiment 04 - Operator Validator

## Aim
To validate whether the given symbol is a valid C operator.

## Pseudocode
1. Read an operator.
2. Compare it with valid C operators.
3. If matched, display "Valid operator".
4. Otherwise, display "Invalid operator".

## Program
The program checks arithmetic, relational, logical, increment, decrement and assignment operators.

## Compilation
```bash
gcc operator_validator.c -o operator_validator.exe
