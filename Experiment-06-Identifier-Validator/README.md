# Experiment 06 - Identifier Validator

## Aim
To develop a lexical analyzer to check whether a given identifier is valid or not.

## Pseudocode
1. Read an identifier.
2. Check whether the first character is a letter or underscore.
3. Check the remaining characters for letters, digits or underscore.
4. Display valid or invalid identifier.

## Compilation
gcc identifier_validator.c -o identifier_validator.exe

## Execution
.\identifier_validator.exe

## Result
The given identifier was successfully validated.
