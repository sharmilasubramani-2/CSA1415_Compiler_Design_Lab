# Experiment 05 - Whitespace Counter

## Aim
To count spaces, tabs and newlines in the given input.

## Pseudocode
1. Read characters until EOF.
2. Check for space, tab or newline.
3. Increment the corresponding counter.
4. Display the counts.

## Compilation
gcc whitespace_counter.c -o whitespace_counter.exe

## Execution
.\whitespace_counter.exe

## Result
The whitespace characters in the given input were successfully counted.
