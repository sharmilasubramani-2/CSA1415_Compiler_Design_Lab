# Experiment 11 - Symbol Table Operations

## Aim

To implement a C program to perform symbol table operations such as insertion, searching, deletion, and display.

## Algorithm

1. Start the program.
2. Create a symbol table to store symbol name, data type, and value.
3. Display the menu containing Insert, Search, Delete, Display, and Exit operations.
4. For Insert, read the symbol name, data type, and value and store them in the symbol table.
5. For Search, compare the entered symbol name with the symbols stored in the table.
6. For Delete, find the specified symbol and remove it from the table.
7. For Display, print all symbols with their corresponding type and value.
8. Repeat the operations until Exit is selected.
9. Stop the program.

## Program

See `symbol_table.c`.

## Sample Output

The program successfully performs:
- Symbol insertion
- Symbol searching
- Symbol deletion
- Symbol table display

## Result

Thus, the C program to perform symbol table operations was implemented and executed successfully.
